## 🌟 Overview
Kickstart your microservices with Go. This boilerplate implements a blazing fast HTTP server using Go Fiber, complete with secure JSON Web Token (JWT) authentication, structured routing, and environment variable management.

## ✨ Key Features
- ⚡ **Fiber Powered**: Built on top of Express-inspired Go Fiber.
- 🔐 **JWT Security**: Ready-to-use login and protected route middlewares.
- 📦 **Clean Architecture**: Structurally organized for scalability.

## 🚀 Getting Started

### Prerequisites
Make sure you have `Go` installed on your local machine.

### Installation
```bash
git clone https://github.com/HafezMosleh/go-fiber-jwt-auth.git
cd go-fiber-jwt-auth
go mod tidy
```

### Usage
```bash
go run main.go
```
