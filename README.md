# go-fiber-jwt-auth

Go Fiber backend boilerplate with JWT authentication, GORM, and PostgreSQL.

## Features
- 🚀 Fast and optimized
- 🔒 Secure by default
- 🛠 Easy to configure

## Installation
```bash
git clone https://github.com/HafezMosleh/go-fiber-jwt-auth.git
cd go-fiber-jwt-auth
```
